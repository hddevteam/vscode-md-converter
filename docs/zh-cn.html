强大功能

高效准确转换文档所需的一切功能，并在 Windows 上更稳定可靠

Word文档

将.docx和.doc文件转换为Markdown，同时保留格式、 标题、列表和表格。

Markdown转Word ⭐

新增：增强的 Markdown 转 Word 功能。 支持智能列表编号、嵌套列表、引用块隔离以及保留换行符，生成更专业的文档。

Excel表格 ⭐

将.xlsx、.xls和.csv文件转换为清晰的Markdown表格或CSV格式。 新功能：支持选择特定工作表进行导出，高级范围选择功能。

PDF文档 ⭐

从PDF文件中提取和优化文本，或将PDF页面转换为高质量PNG图片。 新功能：支持按指定页面导出，精确选择需要的页面范围。

表格提取

智能检测并直接从Word和PDF文档中提取表格为CSV格式， 支持多种格式化选项。

PDF转图片

将PDF页面转换为高质量PNG图片，自动检测工具并提供 跨平台poppler-utils安装指导。

PowerPoint演示文稿 ⭐

将.pptx和.ppt文件转换为Markdown，包含幻灯片内容、演讲者备注和智能文本结构保持。 新功能：支持选择特定幻灯片进行导出，精确控制转换范围。

多选转换 🆕

v0.3.0 新功能：在VS Code资源管理器中选择多个文件，一次性全部转换为Markdown。 可在单次操作中混合不同文件类型，支持自定义输出信息块。

批量处理

一次处理整个文件夹的文档，具有智能 文件类型检测和批量操作功能。

多语言支持

自动语言检测，全面的中英文 界面支持，面向全球用户。

简易集成

右键菜单和命令面板集成， 无缝融入工作流程。

Windows 兼容性优化（v0.5.3）

重点优化 Windows 平台运行兼容性，带来更稳定的转换体验、 更可靠的命令执行与更少的中断。

使用方法

多种方式转换您的文档

右键菜单

在VS Code资源管理器中右键点击任何支持的文档文件， 选择相应的转换选项。

命令面板

按 Ctrl+Shift+P 并输入转换命令， 如"将Word转换为Markdown"。

批量处理

右键点击文件夹批量转换多个文档， 支持自定义选项。
