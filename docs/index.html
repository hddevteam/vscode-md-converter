Powerful Features

Everything you need to convert documents efficiently while preserving tables reliably

Word Documents

Convert .docx and .doc files to Markdown while preserving formatting, headings, lists, and DOCX tables as Markdown table syntax.

Markdown to Word ⭐

NEW: Enhanced Markdown to Word conversion. Smart list numbering, nested list support, preserved line breaks, safer table parsing, and structured diagnostics for professional documents.

Excel Spreadsheets ⭐

Transform .xlsx, .xls, and .csv files into clean Markdown tables or convert Excel files directly to CSV format. NEW: Worksheet export - Select specific worksheets for conversion.

PDF Documents ⭐

Extract and optimize text from PDF files or convert PDF pages to high-quality PNG images. NEW: Page range export - Select specific page ranges for precise conversion.

Table Extraction

Extract tables from Word and PDF documents directly to CSV format with intelligent detection and formatting options.

PDF to Images

Convert PDF pages to high-quality PNG images with automatic tool detection and cross-platform installation guidance for poppler-utils.

PowerPoint Presentations ⭐

Convert .pptx and .ppt files to Markdown with slide content, speaker notes, and smart text structure preservation. NEW: Slide export - Select specific slides for conversion.

Multi-Select Conversion 🆕

NEW in v0.3.0: Select multiple files in VS Code Explorer and convert them all to Markdown at once. Mix different file types in a single operation with customizable output information blocks.

Batch Processing

Process entire folders of documents at once with intelligent file type detection and bulk operations.

Multi-Language

Automatic language detection with full English and Chinese interface support for global users.

Easy Integration

Right-click context menus and command palette integration for seamless workflow integration.

Table Fidelity (v0.5.4)

Word to Markdown now keeps DOCX tables as Markdown tables, while Markdown to Word preserves empty cells, escaped pipe characters, and reports structured diagnostics if conversion fails.

Quick Installation

1

Open VS Code Extensions

2

Search for Extension

3

Install & Start Converting

Click Install and start converting your documents immediately

How to Use

Multiple ways to convert your documents

Context Menu

Right-click on any supported document file in the VS Code explorer and select the appropriate conversion option.

Command Palette

Press Ctrl+Shift+P and type conversion commands like "Convert Word to Markdown".

Batch Processing

Right-click on folders to batch convert multiple documents with customizable options.
